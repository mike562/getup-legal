# Getup — legal & support pages

Public policy and support pages for **Getup**, the Halloween costume
try-on app for iPhone, served via GitHub Pages:

- **Privacy Policy** — https://mike562.github.io/getup-legal/privacy.html
- **Terms of Service** — https://mike562.github.io/getup-legal/terms.html
- **Support** — https://mike562.github.io/getup-legal/support.html
- Index — https://mike562.github.io/getup-legal/

## About this repo

These are static HTML pages (no build step, no scripts, no tracking).
`style.css` matches the app's design language in light and dark mode.

The canonical text of the privacy policy and terms lives in Getup's
private application repository (`docs/privacy-policy.md`,
`docs/terms-of-service.md`) and is also readable inside the app under
**About**. When the canonical documents change, these pages are
regenerated and pushed so the app, the repo, and the public URLs never
drift.
